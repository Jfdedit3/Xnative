Cette clé publique sert uniquement aux APK de développement de Xnative.
Alias : androiddebugkey ; mots de passe de test : android.
Elle est versionnée pour que les builds locaux et GitHub Actions aient la même
signature et puissent mettre à jour le package com.jfdedit3.xnative.android.
Ne jamais utiliser cette clé publique pour une distribution de production.
